# SITARA Definition of Done

A feature is not complete until applicable items below pass.

- [ ] Acceptance criteria and authorization rules are written down.
- [ ] Test was written before or alongside implementation and checks real behavior.
- [ ] Negative cases and unauthorized access paths are tested.
- [ ] Unit and integration tests pass; relevant regression tests are included.
- [ ] Backend lint, format, and type checks pass.
- [ ] Frontend lint, format, type check, tests, and production build pass.
- [ ] Gitleaks, Semgrep, and dependency audits have run; findings are reviewed.
- [ ] Database changes are represented by an Alembic migration.
- [ ] Logs avoid credentials and restricted meeting content.
- [ ] Audit events exist for security-relevant actions.
- [ ] Documentation and operational notes are updated.
- [ ] Independent review has no unresolved critical/high issue without an explicitly approved disposition.
- [ ] No production credentials or real sensitive data are used in development/test.
